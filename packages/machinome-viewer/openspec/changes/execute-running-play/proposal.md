## Why

The complex Vault needs machinome's ratified version-9 running `play` edge to collect wheels at clearance flanks and release them on reversal. The viewer currently advertises and executes only document versions 1 through 8, so without an independent consumer change the browser must correctly refuse that machine.

## What Changes

- Accept and strictly validate document version 9 and its explicit `kind: "play"` program edge.
- Execute play/backlash edges in the running worker with the producer's exact projection, retained bank, chain restrictions, atomic requests, and original-input-prefix stop localization.
- Copy the regenerated framework running corpus byte-for-byte and require coverage and exact/toleranced parity for play, including cascades, reversal, stops, and restore/reset.
- Raise the viewer API from 21 to 22 and report document versions 1 through 9 from the package's single declarations.
- Add malformed-document, unit, worker/runtime, and real-page smoke coverage without changing versions 1 through 8.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `viewer-package`: load, validate, execute, and display version-9 running programs carrying play edges.
- `viewer-distribution`: advertise viewer API 22 and document versions 1 through 9 from the built artifact and entry point.

## Impact

The AGPL widget's running loader and engine, worker-facing behavior, committed conformance corpus, browser tests, package declarations, README, changelog, architecture decision log, and bundle metadata change. The Apache framework remains a separate producer and no code crosses the repository boundary.
