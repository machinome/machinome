## Why

OperatingCurta needs a pointwise angular-contact flag to select its existing numeric axial Bound limits. Its measured outward covers contain the native pinion and drum profiles, but spelling their 591 × 1,072 convex-piece comparisons as ordinary arithmetic creates an unusably large expression graph: a 256-pair slice already produced 49,833 unique nodes. The browser must execute the same finite data-driven predicate as the framework without importing CAD, changing Bound admission, or claiming a swept-contact certificate.

## What Changes

- Read a producer-declared table of finite convex planar profiles and evaluate one `profileOverlap` expression call over two table indices and explicit rigid XY placements. AABB rejection followed by SAT tests whether any polygon pair overlaps or touches; the call returns numeric `0` or `1` for use inside an otherwise ordinary numeric Bound expression.
- Validate the new table and call at document load, reject malformed or unsupported data and nonfinite runtime placements by name, and keep profile data out of the ordinary expression DAG. Scope evaluation to the loaded program so two mounted documents cannot share the wrong table through expression caches.
- Reuse only successful identical placed profiles and contact results inside one running integration attempt, with finite IEEE-exact keys and bounded private storage. The originating installed Curta trial repeats 3,120 placements but has only 136 distinct placement keys in one tick; this is a measured execution-cost gate, not a new public capability.
- Gate the producer's new document version and the viewer's new capability version; preserve versions 1–12 and their existing running results. No span kind, search sampling, admission rule, tolerance, mesh Boolean, viewer CAD dependency, or host API operation is added.

## Capabilities

### New Capabilities

- `finite-convex-profile-contact`: A serialized finite convex-profile table and pointwise numeric overlap predicate for a running machine's existing expressions.

### Modified Capabilities

- `viewer-package`: Loading and version-gating a document that declares the new profile table and expression call while preserving legacy documents and multi-mount isolation.
- `user-documentation`: State the source-only API 26/document-13 capability and its pointwise scope on the owning compatibility/running reference surfaces, without attributing it to the recorded 0.7.0/API-25 baseline or asserting an upload/publication that has not been verified.

## Impact

The viewer's running-document loader, expression scope/evaluator, determined-bound fast path and conformance fixtures change. The framework separately owns the producer API, version-13 wire and reference numeric implementation; this AGPL viewer owns only its reader and browser execution. The originating Curta project's native-only .005 mm outward cover is presently evidence for the computation, not a completed installed-print/contact or continuous-motion certificate; project adoption remains a separate gate.
