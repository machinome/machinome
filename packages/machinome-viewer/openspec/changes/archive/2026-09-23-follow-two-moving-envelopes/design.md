## Decisions

1. **Distinct versioned edge.** Load Follow only from the producer's version-12 declaration, with ordered source needs and one retained bank give. Validate source/give identifiers, unique writer, order/cycles, finite feasible rest interval, authored boundary expressions and structurally matching dynamic lower/high Bounds before mounting. Also refuse any downstream compiled edge that reads the retained Follow target; the required Bounds remain valid readers. This first contract is terminal because a net delta would misrepresent swept interior motion to a downstream law. The producer wire is `kind: 'follow'`, `needs: [lower_source, upper_source, retained]`, `gives: [retained]`, `lower` and `upper` graph expressions, `lower_plan` and `upper_plan` as null or the existing serialized `{skeleton,jumps}` law-plan format, plus ordinary `description` and `stated_by`. Each graph may read the two source names but not the retained name. The viewer must consume producer-authored plans for modulo/floor cuts; it has no equivalent runtime jump compiler. The pinned serializer fixture remains a hard gate before implementation. Viewer API moves from 24 to 25 because a host can require this new execution capability; the producer owns document version 12, used only when Follow is present. Alternative rejected: treating the edge as an old law or variable-width Play would silently change existing documents or violate Play's one-source fixed-offset contract.
2. **Complete certified boundary paths.** Accept only source coordinates rooted in run inputs through unbranched affine determiner chains, as the producer does; refuse an unexpected non-affine source path atomically. Reuse the existing expression/producer-plan jump and kink partition machinery to derive cut locations and certify affine pieces from actual source Motion. Evaluate each frozen-branch boundary expression at its actual source values, not by accumulating `lawMotion` output increments as an absolute envelope: the producer found a real integrated one-ULP drift at Curta's 6° vertex. Inspect both one-sided values and the exact value at each cut. A discontinuity requiring unsupported instantaneous contact, or an unclassified/curved segment, refuses by name before state is committed. Curta's measured one-ULP numeric chart join must be processed as two distinct values without tolerance-based merging, and shown not to cause unsupported contact. Alternative rejected: a prescribed sparse sample or endpoint clamp can miss a push-and-retreat inside one tick.
3. **Ordered retained projection.** Sweep the union of both paths' cuts in time order, splitting affine pieces at lower/follower, upper/follower and lower/upper contact fractions as needed. Apply the producer's ordered projection `q_next = max(L, min(q_prev, U))`, preserving the retained q in free space and its absolute landing at every push. Implement Python's first-operand-on-equality `min`/`max` with ordered comparisons: JavaScript `Math.min`/`Math.max` choose signed zero by rule and would change bank bits at ±0 ties. A transient `L>U` is not thrown away during a probe: ordered projection yields q=L, so the separately declared upper Bound sees positive `q−U`; an inverted interval at rest is refused at load. This order and its floating-point operations must match the producer's accepted algorithm exactly. Alternative rejected: throwing on inversion would preempt the existing Bound search; projecting only the endpoint would erase interior history.
4. **Existing stop machinery plus certified Follow contacts, exact landing.** Follow is untraced like Play for constraint search: each evaluation replays the full prefix from the committed bank, including the swept follower and both boundaries, and carries the follower's absolute landing into Bound evaluation. The ordinary tick uses the same path and landing. Merely using the existing 65 uniform Bound samples is insufficient: a narrow `L>U` interval can begin and end between samples. The producer contract requires matching lower/high dynamic Bounds and supplements the search with the union of certified boundary-piece cuts and both one-sided values. On their common affine refinement, `L−U` is affine, so a strictly positive maximum must occur at a piece endpoint. A representable left probe is used only when it captures an analytically positive left limit; otherwise the producer must define an explicit unsupported-precision refusal rather than silently pass it. The existing first-outward attribution, truncated commit, stop record, relief and snapshot replay then operate on the augmented bracket. A sub-1/64 transient inversion fixture is a prerequisite. Alternative rejected: relaxing the first-contact promise to the existing uniform sample resolution.
5. **Parity before advertising.** Red-first viewer tests cover free retention, inward/outward push, interior excursion, cut-side jumps/refusal, inversion search, opposing-source attribution, restore/replay and legacy behavior. Copy only the producer's accepted generated corpus, compare complete bank/outcomes and actual Curta trial at its frozen export, then update one API/document-version declaration and rebuild/install the package bundle. A browser pointer gate proves the mounted operating control and terminal state; it does not claim interactive tempo unless measured.

## Risks / Trade-offs

- **A cut hides a left-side limit** → inspect each ordered piece's two side values as well as `Motion.at(cut)`; refuse unsupported instantaneous contact or missing certification. The actual Curta bell graph has a measured one-ULP side mismatch at one cut. Treating an arbitrary agreement tolerance as exact continuity is not permitted while Bound contact is strict; exact one-sided handling or a project-authored chart correction must resolve this before applying the cycle.
- **The follower is invalid only between sampled points** → inspect both one-sided values at every common-affine piece cut as analytic evidence, add representable positive contact probes to the Bound search, and explicitly refuse an unrepresentable micro-interval. A sub-1/64 transient inversion test must fail before this addition and pass after. Uniform Bound samples alone cannot prove the first incompatible interval.
- **Inversion throws before admission** → keep ordered projection defined during probes, report violation through the upper Bound, and refuse only infeasible initial state.
- **A stale absolute landing loses contact through cancellation** → carry Follow landing to ordinary commit and constraint evaluation exactly as producer does, with large-offset parity cases.
- **New edge leaks into old documents** → version-gate Follow, keep old law/Play dispatch untouched, and rerun old corpus and browser tests.
- **Signed-zero tie drifts between runtimes** → use ordered first-operand comparisons for the two projection operations and pin every lower/current/upper ±0 tie in the producer corpus at IEEE-bit level.
