# OperatingCurta flat-bank scope experiment — rejected

The pinned higher-counter OperatingCurta export (`manifest.json` SHA256 `f58da4f21142d452bd6de58adc901fafa131d81fcaaf301df7fc767f2269dc67`, 213 coordinates, program identity `4127d33c87f1501a024ee5c7391d1897ce3af65309b946c811d4244c7fd68da2`) was run without WebGL at default `dt=1/240`, after setting selector 1 and requesting a declared 360° crank turn over 2 seconds. The diagnostic covers the first 48 of 480 ticks and 36° of admitted travel only, not a complete operation.

The baseline V8 profile attributed 2.974 seconds of self time to rebuilding nested driver scopes (`nest`) in a 22.078 process-CPU-second 48-tick window. An isolated running-only flat-bank scope was therefore tried: exact qualified names read own flat keys, while a lazy nested view retained partial-name, binding, context and native member/error behavior. Red-first tests covered exact reads without constructing nested scope, binding precedence, partial names, signed zero, NaN and key presence; the candidate passed those tests and typecheck. Both baseline and candidate produced sorted full-bank SHA256 `790e76a9aaae36bf703b6aa74f8722771fa87e1379ab6375f033153729a09bb6`, 213 keys and 36° admission.

It did not meet the performance gate. A reserved-CPU15 non-profiled pair measured baseline **20.940** versus candidate **20.687** process-CPU seconds for 48 ticks, only **1.2%** lower. Under V8 profiling the candidate's `nest` self time fell to 1.909 seconds, but `resolveName` rose to 2.119 seconds and GC to 3.527 seconds; total candidate tick CPU was 24.197 seconds. These observations do not establish that the replacement is faster in ordinary use. A full 480-tick turn was not run for this experiment, and the 48-tick timings must not be described as that turn's elapsed time.

All experimental runtime changes and temporary external-project tests were removed. This branch retains its OpenSpec planning proposal and negative evidence but contains no accepted implementation; the proposed capability must not be synced or archived as implemented.
