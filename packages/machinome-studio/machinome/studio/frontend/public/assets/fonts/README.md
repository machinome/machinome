# Interface fonts

The two faces the Machinome identity names for products, unchanged from
the Google Fonts distribution the identity pins, each under the SIL Open
Font License 1.1 in the notice beside it:

- `SpaceGrotesk.ttf`, Space Grotesk by Florian Karsten, variable weights
  300 to 700: the interface face, for headings, controls and prose.
- `IBMPlexMono-Regular.ttf`, IBM Plex Mono by IBM, regular weight only:
  the technical face, for code, paths, values and annotations.

Keep the notices when redistributing the fonts. The stylesheet asks for no
weight IBM Plex Mono lacks and forbids synthesised ones.
