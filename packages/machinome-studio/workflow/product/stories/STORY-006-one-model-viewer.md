# STORY-006: See one model viewer everywhere

Source: `SPRINT-002-one-model-viewer`

As a maker, I want a model to look and behave the same wherever I see it — on
the shop floor, in an exported directory, in the documentation, and in the live
development loop — so that what I can inspect does not depend on which surface
I happen to be looking at.

As the framework's developer, I want an improvement to that viewer to reach
every surface at once, so that a viewer capability is designed, proven, and
maintained once.

Publishing the viewer for use outside this workspace is outside this story.
