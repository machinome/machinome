## Why

Leonardo's `machinome-dark-sequence` and `machinome-syntax-study` had to leave the supported Videomaker format to cut from the real moving sawmill to readable source alone and back. Format 0.4 already films model-only and source/model split shots, but a code-bearing shot cannot suppress the competing model view; the disposable experiment's private renderer is not a sustainable episode workflow.

## What Changes

- Add `layout: source-only` as one opt-in format-0.4 shot field, valid only with that shot's existing pinned `code` excerpt. With the field absent, no-code shots remain model-only and code shots remain the existing split, with exact old pixels.
- Show the existing literal, typed and optionally narration-emphasized source in the film's available picture region, without a model canvas in that shot's own picture, while retaining current episode styling, masthead, series and progress rule. A transition may still reveal its outgoing model as existing joins do. Keep current source pinning, overflow refusals, captions and narration behavior.
- Refuse source-only shots that declare annotations, highlights or pictures, rather than silently aiming at a covered model or applying split-stage picture geometry. Carry each shot's layout into its own incoming and outgoing transition frames and into shot-cache identity; existing transition timing and outgoing continuation rules remain authoritative.
- Prove a short Leonardo model → source-only → model film against current pinned `model.py` line 415, including exact default-layout compatibility and same-instant transition pixels, before claiming the supported path replaces the private experiment for this presentation need.

## Capabilities

### New Capabilities

- `source-only-shots`: Optional format-0.4 source-only presentation, its refusals, transition behavior and exact compatibility with existing model-only/split shots.

### Modified Capabilities

None. Existing code typing, measured emphasis, transitions, pictures and shot-cache requirements keep their current meaning; the new opt-in's additional restrictions and presentation behavior are specified under the new capability.

## Impact

Videomaker's 0.4 episode validation, timeline requests, film page, browser checks, preview and render/cache tests, plus the reader-facing format description. Leonardo owns any demonstration episode and output, not this repository. No viewer API change, new source-range syntax, initial-prefix feature, dark theme, chrome removal, generic layout engine, new speech purchase, mechanical-model change or publication is included.
