======
Movies
======

A narrated film of a machine is made with ``machinome movie``, the command
of the package ``machinome-movie``, which ``pip install "machinome[movie]"``
installs and which is numbered with the framework, |release| with this
release. A movie is declared in Python with ``machinome.movie``
(:doc:`/howto/declare-a-movie`), drawn by its project's stage module
(:doc:`/howto/draw-a-movie-stage`) and filmed by the command
(:doc:`/howto/film-a-movie`). These pages are the lookup: the command, the
document a movie evaluates to, and the YAML episode format.
