# How AI is used in Machinome

Machinome is developed with AI coding agents. This file says which agents,
since when, how they work, and what the Git history records about their
work and what it does not, so that nobody reading this repository has to
guess.

## Three phases

**July 2023 to early 2025: written by hand.** The maintainer, Luis
Fagundes, wrote the code himself, in bursts. Parts of some files in the
first release (solid-node 0.0.1, 13 July 2023) were generated by ChatGPT in
a browser and pasted into the editor by hand; those parts are not marked and
cannot be told apart in the history. The releases of February 2025 (0.0.6
to 0.2) were his work, with one contributor's pull request.

**Late 2025 to January 2026: agents under close direction.** From around
November 2025 the maintainer experimented with AI agents, Claude Code among
them, building projects on solid-node. Most of that work happened in the
repositories around the framework rather than in it: the projects the
agents built and a private platform repository, where the first
architecture decision records were written retroactively with AI and dated
to the decisions they record, which is why ADR-001 to ADR-011 carry 2023
dates. In this repository the trace of that phase is the burst of 10 to 14
January 2026: ADR-018 (the lean framework separation) and ADR-021 (the
snapshot command, written so that agents could see what they build)
implemented, `CREDITS.md` added and 0.3.0 prepared, a version tagged and
never uploaded. The maintainer directed that work closely and made the
commits himself; they carry no trailer, and which lines an agent wrote
cannot be recovered from the history. The decision records were moved into
this repository on 18 July 2026.

**From 12 July 2026: entirely agentic.** Commit `81a330a`, dated 12 July
2026, is the first commit carrying a Claude Code trailer. From there on,
every line of code and text committed to this repository is written by an
agent under the maintainer's direction and review, and he has written no
code since. A commit after that date is agent work whether or not it says
so.

## Two agents, and how the history marks them

Two agent tools have been used since the line:

- **Claude Code** (Anthropic), the agent of the late-2025 experiments and
  of every day since 12 July 2026. It appends a `Co-Authored-By: Claude …`
  trailer naming the model to every commit it makes.
- **Codex** (OpenAI), from the third week of July 2026; its first recorded
  use in the development workspace is dated 20 July 2026. It appends no
  trailer, and the maintainer did not enforce one.

So the trailers undercount agent work. As of 28 September 2026, 612 commits
follow the line: 387 carry a Claude trailer and the other 225 were made with
Codex. All 612 are agent work. Every commit is authored under the
maintainer's name because he makes them from his own account and answers
for them.

Nothing else in this repository is individually marked as machine-written.
The manual under `docs/`, the architecture synthesis and the ADRs, the
OpenSpec records and the notes under `workflow/` written since the line are
agent-written like the code, and reviewed the same way.

## How the agents work

The maintainer sets the interface, the top-level architecture and the
distribution of components. What gets built is decided empirically:
mechanical projects, existing open-source machines simulated by agents and
historical machines reconstructed by agents, produce findings; a finding
becomes a framework requirement; another agent implements it.

Every change runs through the discipline `README.rst` and `CONTRIBUTING.rst`
describe, adopted on 18 July 2026: proposed as an OpenSpec change, ratified
by the maintainer before implementation, implemented test-first with the
failing test seen before the fix, with rendered geometry inspected rather
than trusted to a green suite, and archived with its record. Architectural
decisions are recorded as ADRs. Agents never publish: tagging, pushing and
uploading to PyPI are the maintainer's own actions.

The maintainer's review is of design and behaviour. He ratifies each
proposal, reads the change records, runs and inspects the results, and
decides what integrates. He does not claim to have read every line the
agents wrote.

The agents are tools. The maintainer publishes their output under this

recipient's choice, holds the copyright `LICENSE` states,
and is responsible for it. No model is an author of Machinome.

## The other repositories

The same practice and the same line apply to the sibling repositories:
machinome-viewer, machinome-mechanics, molejo, machinome-studio,
machinome.org and the Foundry projects under
<https://github.com/machinome-foundry>. molejo, machinome-mechanics,
machinome.org and the Foundry projects were founded after the line and are
agent-written throughout; machinome-viewer's history before the line is
this repository's, from which it was split. Text a model wrote for
machinome.org is marked there file by file with the model and the date.
