## Why

The Curta Type I's running reverser needs an angular contact decision between its installed counter-pinion and stepped-drum profiles inside an existing axial `Bound`. The project's direct symbolic SAT construction would require 633,552 convex-polygon pairs for just one pinion/nine-tooth drum pairing; a capped 256-pair probe already produced 49,833 distinct expression nodes, while the viewer's normal reclaim trigger is 125,000 nodes. A finite profile predicate evaluated from compact data is needed before that existing law can be made portable.

The originating project is `projects/Calculators/Curta-Type-I-3x`. Its four source-profile covers have exact native outside remainder zero, and eight placed probes agree with native contact. The standalone published meshes of both drum segments have positive material outside those native-only covers, so the project is investigating a union with independently supplied projected mesh triangles. These are **investigation results, not an accepted installed-print contact certificate**: complete installed-print, axial-band and retained-running admission proofs remain owed. This change must not declare those obligations complete.

## What Changes

- Add `ConvexProfile` and `profile_overlap` from `machinome.simulation.profile`: a finite value accepting independently supplied convex polygon coordinate loops and a pointwise, rigid-XY numeric 0/1 predicate usable in a running `Bound` expression. The predicate uses AABB rejection and SAT over the declared convex pieces; touching outward covers counts as contact, with no epsilon, CAD call, volume verdict or claim about an unsampled rotational path.
- Publish profiles once as immutable polygon data in a version-gated running program, with small scalar `profileOverlap(...)` expression calls naming literal profile-table indices and their angle/translation operands. Validate the data and references, keep them owned by the program/expression rather than a mutable global registry, and include them in snapshot/program identity.
- Reuse successful placed-profile and pair decisions only within one bounded running integration attempt for exact repeated finite operands. The originating installed Curta trial exposed 3,120 preparations but only 136 exact placement keys in one tick; the cache must preserve ordered first errors, signed-zero distinctions, run isolation and the existing numeric predicate.
- Keep the existing numeric lower/upper `Bound` limits, 64-sample contact search, bisection, stop attribution, and old document behavior unchanged. Curta's trial uses the new flag only to select its existing held-coordinate-side absolute axial stopping planes.
- Prove the capability with a producer conformance fixture, the actual source-profile witnesses and a bounded Curta local trial of stop/relief/replay, paired with a separately reviewed viewer consumer change before claiming browser parity. Full installed-print/axial/production adoption remains a separate project obligation, not a prerequisite for accepting this pointwise capability.

## Capabilities

### New Capabilities

- `convex-profile-contact`: finite convex profile declaration, rigid planar placement, pointwise inclusive-contact predicate, validation and lifecycle.

### Modified Capabilities

- `simulation`: admit the compact predicate as a numeric term inside a running `Bound` while retaining the existing constraint and stop semantics.
- `export`: carry the immutable profile table and scalar call in a newly gated running document, with correct program identity and viewer-version refusal/warnings.
- `user-documentation`: test the public import/docstring contract and record the v13 capability as current source in status and unreleased changelog, without rewriting released 0.7 claims.

## Impact

Framework Python expression compilation/evaluation, running-bound validation and publication, document versioning, public docstrings, current-source status/changelog, tests and conformance fixtures; paired `machinome-viewer` loader/evaluator change in its own repository. No source solid, mesh, step size, contact tolerance, ordinary `Play`/`Follow` law, or existing numeric `Bound` is changed. The project must independently finish native-and-published-mesh cover and operating admission evidence before adopting the predicate as a reverser restraint.
